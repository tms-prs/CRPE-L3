# Leçon 01 — Nombres relatifs et opérations

**Domaine** : Nombres et calculs
**Programme** : cycle 4 — addition / soustraction en 5e, multiplication / division en 4e (BO du 5 mars 2026, annexe 2)
**Prérequis** : décimaux, droite graduée, priorités opératoires, distributivité simple
**Durée conseillée** : 1 h 30 (cours) + exercices

---

## Objectifs

À la fin de la leçon, l'étudiante sait :

- définir un nombre relatif, son opposé, sa valeur absolue ;
- comparer et ranger des relatifs ;
- calculer sommes, différences, produits, quotients de relatifs ;
- **justifier** la règle des signes (et pas seulement l'appliquer) ;
- enchaîner des opérations avec les priorités ;
- repérer les erreurs types d'élèves et proposer une remédiation.

---

## 1. Définitions

### 1.1 Nombres relatifs

Un **nombre relatif** est un nombre précédé d'un signe `+` ou `−` (ou pour lequel ce signe est sous-entendu). Exemples : `+3`, `−7,5`, `0`, `−2/3`.

- Un nombre est **positif** s'il est ≥ 0, **strictement positif** s'il est > 0.
- Un nombre est **négatif** s'il est ≤ 0, **strictement négatif** s'il est < 0.
- `0` est à la fois positif et négatif ; c'est le seul.

Les relatifs ont été introduits pour que **toute soustraction soit possible** : `3 − 5` n'a pas de résultat dans les entiers naturels, mais vaut `−2` dans les relatifs.

> **Contextes d'emploi** : température, altitude / profondeur, dates avant / après J.-C., compte en banque (crédit / débit), niveaux d'étage.

### 1.2 Repérage sur une droite graduée

Sur une droite graduée, chaque point a une **abscisse** (un nombre relatif). Le point d'abscisse `0` est l'origine. Les positifs sont à droite, les négatifs à gauche.

```
 ◄──┼────┼────┼────┼────┼────┼────┼────┼──►
   −3   −2   −1    0   +1   +2   +3   +4
```

### 1.3 Opposé

L'**opposé** de `a` est le nombre noté `−a` tel que `a + (−a) = 0`.

- L'opposé de `5` est `−5` ; l'opposé de `−5` est `5` ; l'opposé de `0` est `0`.
- Deux nombres opposés sont **symétriques par rapport à 0** sur la droite graduée.
- Attention : `−a` n'est pas forcément négatif. Si `a = −4`, alors `−a = 4`.

### 1.4 Valeur absolue (distance à zéro)

La **valeur absolue** de `a`, notée `|a|`, est la distance entre `0` et le point d'abscisse `a`.

- `|a| = a` si `a ≥ 0` ; `|a| = −a` si `a ≤ 0`.
- `|−6| = 6`, `|6| = 6`, `|0| = 0`.
- Une valeur absolue est toujours positive ou nulle.

---

## 2. Comparer et ranger

Sur une droite graduée, **un nombre est plus petit que tous ceux qui sont à sa droite**.

Règles :

1. Tout nombre négatif est plus petit que tout nombre positif.
2. Entre deux positifs : le plus grand est celui qui a la plus grande valeur absolue.
3. Entre deux **négatifs** : le plus grand est celui qui a la **plus petite** valeur absolue. Exemple : `−2 > −7` (car `|−2| < |−7|`).

**Exemple.** Ranger dans l'ordre croissant : `3 ; −1,5 ; 0 ; −4 ; 2,5`.
Réponse : `−4 < −1,5 < 0 < 2,5 < 3`.

---

## 3. Addition

### 3.1 Sens

Additionner `b` à `a`, c'est se déplacer de `b` à partir de `a` : vers la droite si `b > 0`, vers la gauche si `b < 0`.

### 3.2 Règles

| Cas | Règle | Exemple |
|---|---|---|
| Même signe | On additionne les valeurs absolues, on garde le signe commun | `(−3) + (−5) = −8` |
| Signes différents | On soustrait la plus petite valeur absolue de la plus grande, on garde le signe du terme de plus grande valeur absolue | `(−7) + (+4) = −3` ; `(+7) + (−4) = +3` |
| Opposés | La somme est nulle | `(−6) + (+6) = 0` |
| Avec 0 | `0` est neutre | `(−3) + 0 = −3` |

L'addition est **commutative** (`a + b = b + a`) et **associative** : on peut regrouper positifs d'un côté, négatifs de l'autre.

**Exemple.** `(−3) + (+8) + (−5) + (+2) = (8 + 2) + (−3 − 5) = 10 − 8 = 2`.

### 3.3 Suppression des parenthèses

- `a + (+b) = a + b`
- `a + (−b) = a − b`

Les parenthèses sont **indispensables** pour séparer deux signes consécutifs : `3 + −5` s'écrit `3 + (−5)`.

---

## 4. Soustraction

**Soustraire un nombre, c'est ajouter son opposé.**

`a − b = a + (−b)`

Exemples :

- `5 − 8 = 5 + (−8) = −3`
- `(−2) − (−7) = (−2) + 7 = 5`
- `(−4) − (+3) = (−4) + (−3) = −7`

Lien avec la distance : la distance entre deux points d'abscisses `a` et `b` vaut `|a − b|`.

**Suppression de parenthèses précédées de `−`** (très fréquent en calcul littéral) :

`a − (b + c) = a − b − c` et `a − (b − c) = a − b + c`.

---

## 5. Multiplication

### 5.1 Règle des signes

- Produit de deux nombres de **même signe** : positif.
- Produit de deux nombres de **signes contraires** : négatif.
- On multiplie les valeurs absolues.

| | `×` | `+` | `−` |
|---|---|---|---|
| **`+`** | | `+` | `−` |
| **`−`** | | `−` | `+` |

Exemples : `(−4) × 3 = −12` ; `(−4) × (−3) = 12` ; `5 × (−2) = −10` ; `0 × (−9) = 0`.

### 5.2 Pourquoi `(−) × (−) = (+)` ? (justification attendue d'un futur enseignant)

**Étape 1 : un seul facteur négatif.** La multiplication est une addition itérée : `3 × (−2) = (−2) + (−2) + (−2) = −6`. Par commutativité, `(−2) × 3 = −6`.

**Étape 2 : deux facteurs négatifs, par la distributivité.** On sait que `2 + (−2) = 0`. Multiplions par `−3` :

```
(−3) × [2 + (−2)] = (−3) × 0 = 0
(−3) × 2 + (−3) × (−2) = 0         (distributivité)
        −6 + (−3) × (−2) = 0
```

Donc `(−3) × (−2)` est le nombre qui, ajouté à `−6`, donne `0` : c'est l'opposé de `−6`, soit `+6`. **On a démontré** `(−3) × (−2) = 6`.

**Autre approche (régularité)** :
`3 × (−2) = −6` ; `2 × (−2) = −4` ; `1 × (−2) = −2` ; `0 × (−2) = 0` ; `(−1) × (−2) = ?`
Le résultat augmente de 2 à chaque ligne : `(−1) × (−2) = 2`. Cette approche **donne l'idée** mais ne démontre pas.

### 5.3 Produit de plusieurs facteurs

Le signe dépend du **nombre de facteurs négatifs** : pair → positif, impair → négatif.
`(−1) × (−2) × (−3) × (−4) = +24` ; `(−1) × (−2) × (−3) = −6`.

### 5.4 Puissances et signes (aperçu)

`(−2)² = (−2) × (−2) = 4` mais `−2² = −(2²) = −4`. Les parenthèses changent le résultat.

## 6. Division

Diviser par un nombre non nul `b`, c'est multiplier par son **inverse** : `a ÷ b = a × (1/b)` (`b ≠ 0`).

**Même règle des signes que la multiplication** :

- même signe → quotient positif ; signes contraires → quotient négatif.

Exemples : `(−12) ÷ 4 = −3` ; `(−12) ÷ (−4) = 3` ; `12 ÷ (−4) = −3`.

**Attention** : la division par `0` est **impossible** (pas de nombre `x` tel que `0 × x = 5`).

Écriture fractionnaire : `(−12)/4 = 12/(−4) = −(12/4) = −3` ; `(−12)/(−4) = 3`.

---

## 7. Enchaînement d'opérations

**Priorités** : (1) parenthèses, (2) puissances, (3) multiplications et divisions (de gauche à droite), (4) additions et soustractions (de gauche à droite).

**Exemple résolu.** `A = 2 − 3 × (−4) + (−6) ÷ 2`

```
A = 2 − (−12) + (−3)          multiplication et division d'abord
A = 2 + 12 − 3                 soustraire = ajouter l'opposé
A = 11
```

**Exemple avec parenthèses.** `B = (−5 + 2) × (3 − 7)`

```
B = (−3) × (−4) = 12
```

**Vocabulaire à maîtriser** : somme, différence, produit, quotient, termes, facteurs. `3 − 2 × 5` est une **différence** de `3` et de `10` ; `(3 − 2) × 5` est un **produit**.

## 8. Problèmes types

**Problème 1 (températures).** À 6 h, il fait −4 °C. À midi, la température a augmenté de 9 °C ; à 18 h, elle a baissé de 5 °C. Quelle est la température à 18 h ?
`−4 + 9 + (−5) = 0 °C`.

**Problème 2 (altitude).** Un plongeur est à −18 m, puis remonte de 7 m, puis descend de 3 m. Altitude finale ?
`−18 + 7 − 3 = −14 m`.

**Problème 3 (écart).** Un thermomètre indique −7 °C à Paris et 5 °C à Rome. Quel est l'écart ?
`5 − (−7) = 12 °C`.

**Problème 4 (preuve).** Montrer que, pour tout nombre `a`, `a − (−a) = 2a`.
`a − (−a) = a + a = 2a`.

## 9. Erreurs types d'élèves (volet didactique)

| Erreur observée | Exemple | Cause probable | Remédiation possible |
|---|---|---|---|
| Ignorer le signe de la parenthèse | `5 − (−3) = 2` | Le `−` devant la parenthèse est lu comme une soustraction simple | Droite graduée ; reformuler « soustraire, c'est ajouter l'opposé » |
| Confondre signe de l'opération et signe du nombre | `−3 + 5` lu comme `−(3 + 5)` | Pas de distinction opération / nombre | Écrire systématiquement `(−3) + 5`, puis simplifier |
| Appliquer la règle des signes de la multiplication à l'addition | `(−3) + (−5) = 8` | Règle « moins et moins font plus » mal comprise | Contexte concret : dettes qui s'ajoutent |
| Se tromper dans l'ordre des négatifs | `−2 < −7` | Comparaison des valeurs absolues | Droite graduée, thermomètre |
| Prendre `−x` pour un nombre négatif | `−a < 0` toujours | Confusion symbole / signe | Tester avec `a = −4` |
| Mal gérer `−2²` | `−2² = 4` | Parenthèses ignorées | Comparer `(−2)²` et `−2²` à la calculatrice |

**Modèles et outils pour enseigner** : droite graduée, thermomètre, ascenseur, jetons positifs / négatifs (une paire `+1`/`−1` s'annule), jeu de cartes.

---

## 10. À retenir

- `a − b = a + (−b)`.
- Même signe : on additionne et on garde le signe. Signes différents : on soustrait, signe du plus grand en valeur absolue.
- Produit / quotient : même signe → `+`, signes différents → `−`.
- Parenthèses indispensables entre deux signes.
- `(−) × (−) = (+)` se **démontre** par la distributivité.
- Division par 0 impossible.
